## Installation

1. Clone repository:

```bash
git clone https://github.com/Atikin132/fun-chat.git
```

2. Go to the project folder:

```bash
cd fun-chat
```

3. Install dependencies:

```bash
npm install
```

## Development server

To start a local development server, run:

```bash
npm run dev
```

After starting the server, open a browser and navigate to `http://localhost:8080/`.

## Building

To build the project run:

```bash
npm run build
```

This will compile your project and save the build files in the `dist/` directory.

## Linting and format

To run linter:

```bash
npm run lint
```

To format code with prettier:

```bash
npm run format
```
